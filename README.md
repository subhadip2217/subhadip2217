## 🧑‍🚀 A little about me

I'm a student and self-driven developer from India who enjoys exploring technology by making things. I like taking an idea, experimenting with it, and gradually turning it into something people can actually use.

- 🔭 **Building:** Android apps, web experiences and creative software experiments.
- 🎧 **Maintaining:** [SubhuMusic](https://github.com/subhadip2217/SubhuMusic), an Android music-player project.
- 🧠 **Exploring:** C, Python, AI-powered ideas, automation and software development.
- 🖥️ **Interested in:** clean interfaces, real-time experiences, music technology and interactive apps.
- ⚡ **Currently driven by:** learning through projects and making each version better than the last.
